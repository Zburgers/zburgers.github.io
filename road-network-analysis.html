Road Network Analysis

Deep learning solution for detecting road networks from satellite imagery

View on GitHub

About the Project

The Road Network Analysis project implements a deep learning solution for detecting road networks from satellite imagery using a UNet++ architecture with EfficientNet-B4 encoder. This cutting-edge approach enables accurate identification and mapping of road networks from aerial imagery, which has significant applications in urban planning, transportation analysis, and disaster response.

The model is trained on high-resolution satellite imagery to segment road networks, producing pixel-wise binary masks that indicate the presence of roads. This technology enables automated mapping and analysis of road infrastructure without manual intervention, greatly improving efficiency and accuracy in geospatial analysis tasks.

Model Architecture

The project uses a UNet++ architecture with an EfficientNet-B4 encoder for road network segmentation:

  • Encoder: EfficientNet-B4 pre-trained on ImageNet for feature extraction
  • Decoder: UNet++ with nested skip connections for improved information flow
  • Output: Single-channel binary segmentation mask indicating road presence

UNet++ improves upon the original U-Net architecture by introducing dense skip connections and deep supervision. This redesigned skip pathways aim to reduce the semantic gap between encoder and decoder features, enabling more precise segmentation of complex road structures.

Code Snippets

model.py
import segmentation_models_pytorch as smp

def build_model(config):
    """
    Build the UNet++ model with EfficientNet-B4 encoder
    
    Args:
        config (dict): Configuration parameters
        
    Returns:
        model: PyTorch model
    """
    # Create UNet++ model with EfficientNet-B4 encoder
    model = smp.UnetPlusPlus(
        encoder_name=config['model']['encoder_name'],      # 'efficientnet-b4'
        encoder_weights=config['model']['encoder_weights'], # 'imagenet'
        in_channels=3,                                     # RGB images
        classes=config['model']['classes'],                # Binary segmentation
        activation='sigmoid'                               # For binary segmentation
    )
    
    return model

def train_epoch(model, dataloader, optimizer, criterion, device):
    """
    Train model for one epoch
    
    Args:
        model: PyTorch model
        dataloader: PyTorch dataloader
        optimizer: PyTorch optimizer
        criterion: Loss function
        device: Device to use for training
        
    Returns:
        epoch_loss: Average loss for the epoch
    """
    model.train()
    epoch_loss = 0
    
    for images, masks in tqdm(dataloader, desc="Training"):
        images = images.to(device)
        masks = masks.to(device)
        
        # Forward pass
        outputs = model(images)
        loss = criterion(outputs, masks)
        
        # Backward and optimize
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        epoch_loss += loss.item()
    
    return epoch_loss / len(dataloader)

Getting Started

To get started with the Road Network Analysis project, follow these steps:

  1. Clone the repository: 
    git clone https://github.com/Zburgers/road-network-analysis.git
cd road-network-analysis
  2. Create and activate a virtual environment: 
    python -m venv venv
source venv/bin/activate  # Linux/Mac
# or
venv\Scripts\activate  # Windows
  3. Install dependencies: 
    pip install -r requirements.txt
  4. Run the project: 
    # For the notebook approach
jupyter notebook main.ipynb

# For the modular approach
python main.py --mode train

The project provides two approaches to model training:

  • Notebook Approach: Interactive and educational with step-by-step visualization, great for development and debugging
  • Modular Approach: Production-ready implementation with better code organization, supporting distributed training and automated logging

Configuration parameters can be adjusted in the config.yaml file to experiment with different model architectures and training strategies.
